# 미아트스쿨 (MiArt School)

학교·학원을 위한 디지털 미술 수업 플랫폼입니다. 아이패드·태블릿·크롬북 브라우저에서 바로 쓰는 웹 앱(PWA)으로, 수업 자료 → 과제 → 그리기 → 제출·피드백 → 갤러리보드 → 마음 날씨까지 한 흐름으로 이어집니다. 화면은 Apple 스타일(유리 상단바, 알약형 버튼, 세그먼트 컨트롤, iOS 스위치·시트)로 디자인했습니다.

- **앱 설치 없음**: iPad Safari에서 "홈 화면에 추가"로 앱처럼 씁니다.
- **자체 서버 운영**: Node.js + 내장 SQLite(`node:sqlite`)만 씁니다. 네이티브 모듈이 없어 Linux 서버, macOS, Windows, **Android Termux**에서 그대로 실행됩니다.
- **오프라인 친화**: 글꼴(Pretendard), QR 라이브러리까지 모두 서버에서 직접 제공해 학교망에서 외부 CDN이 막혀도 동작합니다.
- **AI는 선택**: AI 키가 없어도 AI 주제 도안과 AI 요약을 뺀 모든 기능이 동작합니다.

## 기능

### 랜딩 페이지
상단 메뉴(수업 자료 · 주요 기능 · 이용 후기 · 요금 안내 · 학생 로그인 · 교사 로그인), 도안이 자동으로 색칠되는 아이패드 히어로, 수업 자료 캐러셀, 수채화·유화 **로그인 없이 체험하기**, 마음 날씨·갤러리보드·간편 로그인 소개 슬라이드(실제 앱 화면), 실시간 이용 통계, 이용 후기(관리자가 관리), 요금 안내, 문의·아이디어 제안 폼.

### 학생
| 화면 | 내용 |
|---|---|
| 학생 로그인 | **QR 코드**(카메라로 카드 비추기) 또는 **참여 코드** 6자리 → **동물 그림** → **과일 그림**. 이메일·비밀번호·개인정보 없이 로그인 |
| 대시보드 | 새 과제 배너, 오늘의 마음 날씨 체크인, 진행 중인 과제, 바로 가기, 최근 작품 |
| 마음 날씨 체크인 | 6가지 날씨 + 기분(최대 3개) + 이유 + 선생님께 한마디. 하루 첫 방문에 자동으로 물어봄 |
| 내 과제 | 진행 중 / 제출 완료 / 마감, 기간·도구 표시 |
| 내 작품 | 이어 그리기, 선생님 칭찬 도장 확인, 갤러리보드에 올리기, 새 그림(수채화/유화 · 가로/세로) |
| 갤러리보드 | 우리 반·우리 학교 보드, 작품·사진 게시, 하트로 응원 |
| 그림 마음 탐색 | 집-나무-사람(HTP) 그리기와 질문 |

### 드로잉 스튜디오
- **수채화 모드**: 연필, 크레용, 사인펜, 마커, 수채화 붓, 넓은 수채화 붓, 꽃 브러시, 스프레이, 무지개펜, 페인트 채우기(도안 선을 경계로 인식), 도장, 올가미(선택 후 이동), 스포이드, 지우개
- **유화 모드**: 유화 붓 1~6호, 스머지, 헝겊
- 배경지(흰·미색·크라프트·검정 도화지, 수채화지, 캔버스), 스케치 교재(도안), 수업 자료 패널(안내·활동 순서·유튜브·이미지·링크), 레이어, 실행 취소, 두 손가락 확대 · 두 번 톡으로 원래 크기, 애플펜슬 필압, 펜으로만 그리기, 캔버스 초기화

### 선생님
| 화면 | 내용 |
|---|---|
| 수업 자료 | 학년·도구·계절별 수업안 라이브러리 → **내 수업으로 저장** → 편집(안내·순서·자료 링크·도안·배경지) → **시작하기**(학급·시작·마감 시간 지정 → 과제) |
| 학급 › 학생 | 일괄 등록, 참여 코드·그림 비밀번호 확인/변경/재발급, **QR 로그인 카드 인쇄** |
| 학급 › 과제 | 기간(시작·마감), 수채화/유화, 배경지, 도안, 활동 순서, 수업 자료, 제출 현황 |
| 학급 › 마음 날씨 | 월별 **달력**, 우리 반 평균/학생별 **변화 그래프**, 날씨별 횟수, 오늘의 마음 목록, 연속 비·천둥 학생 표시 |
| 학급 › 제출 작품 | 칭찬 도장 + 한마디, 갤러리보드에 올리기, 내려받기 |
| 갤러리보드 | 우리 반 / 우리 학교(같은 학교 인증 코드의 선생님·학생 모두) 보드, 학생 게시 허용 여부 |
| 학급 › 마음 탐색 | HTP 그림 마음 탐색 학생별·학급 리포트, 선택형 AI 요약 |
| 도안 만들기 | 기본 도안, 사진 → 도안(기기 안에서 처리), AI 주제 도안 |

### 관리자
학교(기관) 인증 코드 발급, 교사 승인, 랜딩 페이지 문의 확인, 이용 후기 관리.

> 마음 날씨와 그림 마음 탐색은 아이를 이해하기 위한 참고 자료이며 진단이 아닙니다. 화면과 리포트에 이 안내가 함께 표시됩니다.

## 빠른 시작

Node.js 22.5 이상이 필요합니다.

```bash
npm install
```

```bash
cp .env.example .env
```

`.env`에서 `ADMIN_EMAIL`, `ADMIN_PASSWORD`를 바꾸고, AI 기능을 쓰려면 `ANTHROPIC_API_KEY`를 넣으세요.

```bash
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다.

## 운영 메모

- **요금·회사 정보**: `shared/site-config.js`의 가격과 사업자 정보는 **예시 값**입니다. 실제 판매 가격과 회사 정보로 바꾸세요. 회사 정보가 비어 있으면 푸터에 표시하지 않습니다.
- **이용 후기**: 데모 데이터에는 "예시 후기"가 들어 있습니다. 관리자 화면에서 지우고 실제로 받은 후기(작성자 동의)만 올려 주세요. 후기가 없으면 랜딩 섹션이 숨겨집니다.
- **HTTPS**: 운영은 HTTPS 리버스 프록시 뒤에서 하고 `COOKIE_SECURE=true`를 설정하세요. **QR 카메라 로그인은 HTTPS(또는 localhost)에서만** 동작합니다. 그 외에는 아이패드 카메라 앱으로 카드를 비추거나 참여 코드로 로그인하면 됩니다.
- **날짜 기준**: 마음 날씨의 "오늘"은 `TZ_NAME`(기본 `Asia/Seoul`) 기준입니다.
- **데이터**: `DATA_DIR`(기본 `./data`)에 DB와 이미지가 저장됩니다. 이 폴더만 백업하면 됩니다.
- **AI 비용**: `AI_DAILY_LIMIT_PER_CLASS`(기본 60회)로 학급별 하루 AI 호출 수를 제한합니다. 모델은 `claude-opus-5-5`, `MIART_AI_MODEL`로 바꿀 수 있습니다.
- **보안**: scrypt 비밀번호, httpOnly 세션 쿠키, 전용 헤더 기반 CSRF 차단, 로그인·그림 비밀번호 시도 제한(10분 8회), 업로드 이미지 시그니처 검사, 작품·게시물·검사 이미지 권한 확인.

## 구조

```
server/            Express 5 API
  routes/          auth · admin · classes · artworks · templates · psych
                   checkins(마음 날씨) · boards(갤러리보드) · lessons(수업 자료) · public(랜딩·문의)
  psych/analyze.js 그림 마음 탐색 분석
  ai/              Claude API · SVG 정리
shared/            서버·브라우저 공용 (도안, 수업 자료, 검사 문항, 체크인, 로그인 그림, 사이트 설정)
public/            빌드 없는 바닐라 JS 프런트엔드
  js/studio/       드로잉 엔진
  js/views/        화면 (landing · student · teacher · boards · checkin · lessons …)
  js/qr.js         QR 생성·카메라 스캔
  vendor/          qrcode-generator(MIT) · jsQR(Apache-2.0) · Pretendard(OFL)
  images/landing/  랜딩 기능 소개 이미지 (실제 앱 화면)
test/              node:test
```
