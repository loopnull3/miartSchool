# 미아트스쿨 (MiArt School)

학교·학원을 위한 디지털 미술 수업 플랫폼입니다. 아이패드·태블릿·크롬북 브라우저에서 바로 쓰는 웹 앱(PWA)으로, 수업 자료 → 과제 → 그리기 → 제출·피드백 → 갤러리보드 → 마음 날씨까지 한 흐름으로 이어집니다. 화면은 Apple 스타일(왼쪽 사이드바, 유리 상단바, 알약형 버튼, 세그먼트 컨트롤, iOS 스위치·시트)로 디자인했습니다.

- **자체 아이콘 세트**: 이모티콘을 쓰지 않고, 미아트스쿨 전용 SVG 아이콘(앱 아이콘, 선 아이콘, 마음 날씨·기분, 로그인 동물·과일 그림, 갤러리보드 아이콘, 드로잉 도구·도장)을 직접 그려 `public/js/icons.js`, `public/js/studio/icons.js`에 담았습니다. 외부 폰트·이모지 렌더링에 의존하지 않아 기기마다 똑같이 보입니다.

- **앱 설치 없음**: iPad Safari에서 "홈 화면에 추가"로 앱처럼 씁니다.
- **자체 서버 운영**: Node.js + 내장 SQLite(`node:sqlite`)만 씁니다. 네이티브 모듈이 없어 Linux 서버, macOS, Windows, **Android Termux**에서 그대로 실행됩니다.
- **오프라인 친화**: 글꼴(Pretendard), QR 라이브러리까지 모두 서버에서 직접 제공해 학교망에서 외부 CDN이 막혀도 동작합니다.
- **AI는 선택**: AI 키가 없어도 AI 주제 도안과 AI 요약을 뺀 모든 기능이 동작합니다.

## 기능

### 랜딩 페이지
상단 메뉴(수업 자료 · 주요 기능 · 이용 후기 · 요금 안내 · 학생 로그인 · 교사 로그인), 도안이 자동으로 색칠되는 아이패드 히어로, 수업 자료 캐러셀, 수채화·유화 **로그인 없이 체험하기**, 마음 날씨·갤러리보드·간편 로그인 소개 슬라이드(실제 앱 화면), 실시간 이용 통계, 이용 후기(관리자가 관리), 요금 안내, 문의·아이디어 제안 폼.

### 학생 (왼쪽 사이드바: 홈 · 과제 · 작품 · 갤러리 · 도안, 휴대폰에서는 아래 탭 막대)
| 화면 | 내용 |
|---|---|
| 학생 로그인 | 학생마다 다른 **QR 코드**(카메라로 카드 비추기) 또는 **참여 코드** 6자리 → **동물 그림** → **과일 그림**. 그림 비밀번호(동물+과일)는 **학급 전체가 같음**. 이메일·비밀번호·개인정보 없이 로그인 |
| 대시보드 | 새 과제 배너, 오늘의 마음 날씨 체크인, 진행 중인 과제, 바로 가기, 최근 작품 |
| 마음 날씨 체크인 | 6가지 날씨 + 기분(최대 3개) + 이유 + 선생님께 한마디. 하루 첫 방문에 자동으로 물어봄 |
| 내 과제 | 진행중 / 마감된 탭, 과제명 검색, 임박순·최신순 정렬, 도안 미리보기 카드와 상태 배지(시작 전·진행 중·임시 저장·제출 완료·마감) |
| 내 작품 | 이어 그리기, 새 그림으로 저장(사본), 선생님 칭찬 도장 확인, 갤러리보드에 올리기, 새 그림(수채화/유화 · 가로/세로) |
| 갤러리보드 | 우리 반·우리 학교 보드, 작품·사진 게시, 하트로 응원 |
| 그림 마음 탐색 | 집-나무-사람(HTP) 그리기와 질문 |

### 드로잉 스튜디오
- **화면 구성**: 위쪽 막대 없이 그림에 집중하는 전체 화면. 왼쪽 위 경로(예: 내 작품 › 드로잉툴), 왼쪽 큰 색 버튼, 화면 가장자리에서 튀어나오는 **가로 도구 그림**(고른 도구는 더 길게 나오고 끝이 현재 색으로 물듦, 한 번 더 누르면 굵기·진하기 창), 오른쪽 위 **나가기 · 저장 · 새 그림으로 저장 · 제출하기 · 수업 자료** 동그란 버튼, 오른쪽 아래 **되돌리기 · 다시하기 · 이동 · 레이어 · 화면 맞춤 · 설정** 세로 막대
- **수채화 모드**: 연필, 크레용, 사인펜, 마커, 수채화 붓, 넓은 수채화 붓, 꽃 브러시, 스프레이, 무지개펜, 페인트 채우기(도안 선을 경계로 인식), 도장(별·하트·꽃·나비 등 18가지 모양을 고른 색으로), 올가미(선택 후 이동), 스포이드, 지우개
- **유화 모드**: 유화 붓 1~6호(크기별 붓), 부채붓(스머지), 헝겊, 채우기, 올가미, 스포이드
- 과제는 선생님이 정한 기법(수채화/유화)으로 고정되고, 자유 그림은 설정에서 바꿀 수 있습니다.
- 배경지(흰·미색·크라프트·검정 도화지, 수채화지, 캔버스), 스케치 교재(도안), 수업 자료 패널(안내·활동 순서·유튜브·이미지·링크), 레이어, 실행 취소, 두 손가락 확대 · 두 번 톡으로 원래 크기, 애플펜슬 필압, 펜으로만 그리기, 캔버스 초기화

### 선생님
**로그인은 이메일만** 입력하면 됩니다(비밀번호 없음). 가입도 이름·이메일·학교 인증 코드만 받습니다. 학급 화면 탭은 **학생 · 과제 · 작품 · 마음 · 설정** 다섯 개이고, 갤러리보드는 왼쪽 메뉴의 '갤러리'에 있습니다.

| 화면 | 내용 |
|---|---|
| 수업 자료 | 학년·도구·계절별 수업안 라이브러리 → **내 수업으로 저장** → 편집(안내·순서·자료 링크·도안·배경지) → **시작하기**(학급·시작·마감 시간 지정 → 과제) |
| 학급 › 학생 | 일괄 등록, **우리 반 그림 비밀번호**(학급 공통 동물+과일) 확인·변경·새로 뽑기, 학생별 참여 코드 확인·재발급, **QR 로그인 카드 인쇄** |
| 학급 › 과제 | 기간(시작·마감), 수채화/유화, 배경지, 도안, 활동 순서, 수업 자료, 제출 현황 |
| 학급 › 마음 › 마음 날씨 | 오늘 체크인 수·관심 필요 학생 한 줄 요약, 월별 **달력**, 우리 반 평균/학생별 **변화 그래프**, 오늘의 마음 목록 |
| 학급 › 작품 | 칭찬 도장 + 한마디, 갤러리보드에 올리기, 내려받기 |
| 갤러리보드 | 우리 반 / 우리 학교(같은 학교 인증 코드의 선생님·학생 모두) 보드, 학생 게시 허용 여부 |
| 학급 › 마음 › 그림 마음 탐색 | HTP 그림 마음 탐색 학생별·학급 리포트, 선택형 AI 요약 |
| 도안 만들기 | 기본 도안 24종, 사진 → 도안(기기 안에서 처리), AI 주제 도안 |

### 관리자
학교(기관) 인증 코드 발급, 교사 승인·수정(이름·**이메일**·학교), 랜딩 페이지 문의 확인, 이용 후기 관리. 관리자 로그인만 비밀번호가 필요합니다.

### 처음부터 들어 있는 계정
서버를 처음 켜면 **범어초등학교 · 최규민 선생님** 계정이 자동으로 만들어집니다(로그인 이메일 `kyumin@miart.school`, 임시 주소). 실제 이메일은 관리자 화면 › 선생님 계정 › 수정에서 바꾸거나, 서버를 처음 켜기 전에 `.env`의 `INITIAL_TEACHERS`를 바꾸세요.

> 마음 날씨와 그림 마음 탐색은 아이를 이해하기 위한 참고 자료이며 진단이 아닙니다. 화면과 리포트에 이 안내가 함께 표시됩니다.

## 서버에 올리기 (호스팅)

필요한 것: Node.js 22.5 이상이 돌아가는 서버(또는 Docker), 그리고 HTTPS용 도메인. 데이터는 `DATA_DIR`(DB + 그림 파일) 한 폴더에 모두 저장됩니다.

### 1) 리눅스 서버 + Docker (권장 — HTTPS 자동)

1. 도메인의 A 레코드를 서버 IP로 연결하고, 서버 방화벽에서 80·443 포트를 엽니다.
2. 소스를 서버에 올리고 압축을 풉니다.
3. 설정 파일을 만듭니다.

```bash
cp .env.example .env
```

4. `.env`에서 `DOMAIN`(예: `miart.example.com`), `ADMIN_EMAIL`, `ADMIN_PASSWORD`(10자 이상)를 바꾸고, AI를 쓰려면 `ANTHROPIC_API_KEY`를 넣습니다.
5. 실행합니다. Caddy가 인증서를 자동으로 받아 `https://도메인` 으로 열립니다.

```bash
docker compose up -d --build
```

- 상태·로그 확인: `docker compose ps`, `docker compose logs -f app`
- 업데이트: 새 소스로 바꾼 뒤 `docker compose up -d --build` (데이터는 `miart-data` 볼륨에 남아 있음)
- Docker Hub 요청 제한(429)이 나면 `docker compose build --build-arg NODE_IMAGE=public.ecr.aws/docker/library/node:22-bookworm-slim` 으로 빌드
- 백업:

```bash
docker compose exec app node scripts/backup.js /data/backups
```

### 2) Docker 없이 (Ubuntu 등 + systemd + Caddy)

1. Node.js 22.5 이상을 설치하고 소스를 `/opt/miartSchool`에 둡니다.
2. 의존성을 설치합니다.

```bash
cd /opt/miartSchool && npm ci --omit=dev
```

3. `.env`를 만들고 `NODE_ENV=production`, `COOKIE_SECURE=true`, 관리자 계정을 설정합니다.
4. `deploy/miart.service`를 `/etc/systemd/system/`에 복사하고(사용자·경로 확인) `sudo systemctl enable --now miart`
5. Caddy를 설치하고 `deploy/Caddyfile.host`의 도메인을 바꿔 `/etc/caddy/Caddyfile`로 넣은 뒤 `sudo systemctl reload caddy`
6. 백업은 `npm run backup` (서버를 멈추지 않고 DB를 안전하게 복사)

### 3) 안드로이드 Termux

```bash
bash deploy/termux-start.sh
```

처음 실행하면 무작위 관리자 비밀번호를 만들어 화면과 `.env`에 남깁니다. 인터넷에서 접속하려면 다른 Termux 창에서 Cloudflare 터널을 엽니다(표시되는 `https://….trycloudflare.com` 주소로 접속, 고정 주소는 Cloudflare 계정의 이름 있는 터널 사용).

```bash
pkg install cloudflared && cloudflared tunnel --url http://localhost:3000
```

### 운영 체크리스트

- 데모 데이터(`npm run seed`)는 운영 서버에서 실행하지 마세요(예시 계정·비밀번호가 만들어짐).
- 관리자로 로그인해 **학교 인증 코드**를 만들고 선생님께 나눠 주면, 선생님이 가입 → 관리자 승인 → 학급·학생 등록 순서로 시작합니다.
- `shared/site-config.js`의 요금·회사 정보, 랜딩 이용 후기를 실제 내용으로 바꿉니다.
- QR 카메라 로그인은 HTTPS에서만 동작합니다.

## 운영 메모

- **요금·회사 정보**: `shared/site-config.js`의 가격과 사업자 정보는 **예시 값**입니다. 실제 판매 가격과 회사 정보로 바꾸세요. 회사 정보가 비어 있으면 푸터에 표시하지 않습니다.
- **이용 후기**: 데모 데이터에는 "예시 후기"가 들어 있습니다. 관리자 화면에서 지우고 실제로 받은 후기(작성자 동의)만 올려 주세요. 후기가 없으면 랜딩 섹션이 숨겨집니다.
- **HTTPS**: 운영은 HTTPS 리버스 프록시 뒤에서 하고 `COOKIE_SECURE=true`를 설정하세요. **QR 카메라 로그인은 HTTPS(또는 localhost)에서만** 동작합니다. 그 외에는 아이패드 카메라 앱으로 카드를 비추거나 참여 코드로 로그인하면 됩니다.
- **날짜 기준**: 마음 날씨의 "오늘"은 `TZ_NAME`(기본 `Asia/Seoul`) 기준입니다.
- **데이터**: `DATA_DIR`(기본 `./data`)에 DB와 이미지가 저장됩니다. 이 폴더만 백업하면 됩니다.
- **AI 비용**: `AI_DAILY_LIMIT_PER_CLASS`(기본 60회)로 학급별 하루 AI 호출 수를 제한합니다. 모델은 `claude-opus-5-5`, `MIART_AI_MODEL`로 바꿀 수 있습니다.
- **선생님 이메일 로그인**: 이메일만으로 로그인하므로 선생님 이메일을 아는 사람은 그 선생님으로 들어올 수 있습니다. 외부에 공개하는 서버라면 학교 이메일처럼 남이 추측하기 어려운 주소를 쓰고, 필요하면 `.env`에 `TEACHER_EMAIL_LOGIN=false`를 넣어 비밀번호 로그인으로 되돌리세요. 승인되지 않은 선생님과 관리자 계정은 이메일만으로 들어올 수 없습니다.
- **보안**: scrypt 비밀번호, httpOnly 세션 쿠키, 전용 헤더 기반 CSRF 차단, 로그인·그림 비밀번호 시도 제한(10분 8회), 업로드 이미지 시그니처 검사, 작품·게시물·검사 이미지 권한 확인.
